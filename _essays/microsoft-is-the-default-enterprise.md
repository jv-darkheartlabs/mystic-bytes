## Thesis

**Microsoft is the default enterprise.** Windows is the desktop you inherit. Office is the document you cannot refuse. Azure is the meter attached to the identity that already knows your org. GitHub is the forge bolted onto that habit. The product is the portfolio, sold as an agreement.

## Context

Dark Heart Labs' public repos live on GitHub. I write in an editor Microsoft invented. I open `.docx` files I did not choose because someone else's legal or finance stack still emits them. I do this from Auckland in 2026 as a customer. I have never been a Microsoft employee. There is a separate essay about GitHub after the 2018 acquisition: the forge still works, Copilot is the extraction layer. This one is wider. It is about why a studio of one still orbits a company built to be the default of institutions.

The default is not a conspiracy. It is decades of being the file format, the login, and the laptop image that procurement already approved.

## Mechanism

**Windows is still the institutional PC.** Consumer market share can wobble. The enterprise image does not. Device management, BitLocker, Entra join, the assumption that a line-of-business app was written for Win32 or a browser Microsoft also ships: this is how "we are a Mac shop" still means "finance runs Windows in a VM." I daily-drive Fedora. I still keep a path to a Microsoft-shaped desktop because vendors I did not pick still test there first. The OS is not winning on taste. It is winning on the install base procurement refuses to re-litigate.

**Microsoft 365 is the document default.** Word, Excel, Teams, SharePoint, Outlook: the suite is a habit with a subscription. Files arrive as `.docx` because the other party's counsel lives in Word. Meetings arrive as Teams because the enterprise agreement already includes it. You can export. You cannot make the other org export. That is how a default works. It does not need to be loved. It needs the counterparty to already have a license.

**Identity is the hinge.** Azure Active Directory, now Microsoft Entra ID, is how the portfolio becomes one login. Conditional access, SSO into GitHub Enterprise, SSO into Azure, SSO into Office: once the directory is Microsoft's, every new SKU is a checkbox, not a migration. I have watched small teams "just add" Copilot or a Power BI seat because the tenant already existed. The tenant is the product. The apps are SKUs hung on it.

**Azure is the meter that loves the tenant.** Intelligent Cloud is a real segment in the annual report: regions, AD, the same identity, the same support contract.[^1] You can run mystic-bytes nowhere near Azure. Plenty of people do. The enterprise path of least resistance is still "the cloud that already knows your people." Incentives do not require a hard lock-in. They require a discount on the bundle and a penalty, social more than technical, for being the person who introduces a second vendor.

**GitHub is the developer graph in the same portfolio.** The 2018 purchase put the forge next to Azure and VS Code. Ownership incentives are the other essay. The portfolio point is simpler: Microsoft now sells the OS, the office, the cloud, the editor, and the place you open the pull request. A default enterprise is a company you can staff an entire job around without learning a second landlord. That is convenient. It is also how exit starts to look like a career change rather than a remote URL.

## Tradeoffs

**One vendor vs exit cost.** A single agreement is cheaper to administer and easier to support. It is also how a pricing change in Copilot, Exchange, or Actions becomes an org-wide event. Mirror the git remotes. Keep a document path that is not only OneDrive. Identity is the hard one; treat a second IdP as insurance if you can afford the boredom.

**Azure vs another cloud.** If your workloads are already Entra-joined and your staff already have Azure muscle, Azure is the rational default. If you are a studio of one on Fedora, it is an optional SKU. Do not buy gravity you do not need.

**When the default is the right buy.** If your counterparties live in Word and Teams, refusing Microsoft is a personality, not a strategy. Use the suite for the handshake. Keep the work you own on tools you can leave. GitHub can be that leaveable tool until the meter says otherwise; the forge essay is the receipt.

## Close

Call Microsoft a portfolio, not a list of apps. Windows, Office, Azure, GitHub: four logos, one agreement, one directory. I will keep using the pieces I actually need. I will stop pretending they are four unrelated shops that happen to share a campus.

The default enterprise is the vendor you inherit. Inherit on purpose, or you will inherit on invoice.
