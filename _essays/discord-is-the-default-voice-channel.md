Discord is what a lot of communities use instead of running a voice server. That is not a vibe. That is infrastructure: persistent text, live voice, roles, bots, Stage channels, threads, and a permission matrix that used to be four different tools.

Dark Heart Labs' public room is [The Perimeter](https://discord.gg/Rw7ZgT52gC). I moderate it from Auckland as a user of the product, not as someone who built Discord. People show up there because their games already trained the muscle: click the channel, unmute, share a screen. IRC could do text. Mumble and TeamSpeak could do voice. Slack can do office chat. Discord bundled the community unit — the *server* — with enough bot API that a small studio can run roles and alerts without standing up a stack. The second-order cost is custody. Search is theirs. Boosts and Nitro are the meter. A policy change or an outage is an outage of the room, not of a VPS you can migrate.

I am not going back to "just run an IRC bouncer" as a growth plan. I am going to treat Discord like GitHub: default because the people are there, mirrored where it matters, with the knowledge that the voice channel is rented.

If the community cannot be exported, it is not yours. It is the default you are paying in attention.

— JV · Dark Heart Labs.
