Oracle's Java OCA is syntax sold as a credential. The associate exam, in the Java SE 8 shape that still lives in job posts, asked you to prove you could read the language: types, control flow, classes. Oracle Certified Professional was the next invoice. Same vendor, more objectives, another Pearson appointment.[^1]

I do not hold OCA or OCP. I am not a Java engineer. There is a separate essay about the JVM as the institution that still runs payroll. This one is the badge. Oracle inherited Sun's certification machine in 2010 and kept the culture: published objectives, a version in the title, a retake fee. Java SE 11 folded associate and professional into one "Developer" exam. Recruiters still type OCA. The lineage outlived the SKU.

The honest product is a shared floor. An exam is a faster filter than a take-home if the org only needs to know you can parse a for-loop. The culture fails when the credential is treated as fluency. Syntax on a Tuesday in a test center is not the runtime you will page. Oracle sells the sitting. Recertification when the SE number moves is the subscription wearing a diploma.

Read the objectives as a product catalog. Do not confuse a passing score with having shipped on the JVM.

— JV · Dark Heart Labs.
